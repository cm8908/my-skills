# delegate-to-subagents

The user wants coding tasks delegated to subagents running an appropriately lower-power model.

Practically: when a coding/implementation task arises, spawn subagent(s) via the Agent tool to do the hands-on coding rather than writing/editing files inline yourself. Pick the subagent's model to match the task's difficulty — prefer a lower-power model (e.g. Sonnet for normal work, Haiku for routine/mechanical edits); reserve the top-tier model only for genuinely hard problems. Keep planning, decomposition, and review of results at your own level, and push the implementation down.
